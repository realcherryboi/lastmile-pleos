# 라스트마일 UI/UX 설계 노트 (Pleos Connect 디자인 가이드 기준)

> 2026-11-05. 근거: document.pleos.ai 디자인 가이드(Introduction·Display Layout·Window Policy·Typography·Colors·Interaction), 앱 리뷰 가이드(운전자 주의 분산·기능/성능 안정성), 앱 구조 모델, 주행 규제 개발 가이드. 순정 내비·클러스터 화면을 시각 레퍼런스로 사용.

## 1. 디자인 원칙 → 적용
| Pleos 원칙 | 적용 |
|---|---|
| Easy & Safe: 1~2초 안에 파악, 한 손 조작 | 화면당 핵심 정보 1개(남은 거리 120sp) + 안내 1문장(40sp) + 사실 3줄. 버튼은 화면 하단 1~2개 |
| 동영상·애니메이션·자동 스크롤 금지 | 상태 전환 시 200ms 크로스페이드만. 반복 애니메이션 없음 |
| 응답 0.25초 | 터치 즉시 95% 수축(80ms) — `Pressable.kt`, 가이드 "shrink effect 95%" 그대로 |
| 일관성(기본 탑재 UI와 통일) | 순정 라이트 테마, 흰 카드 + 검정 필 버튼, 28dp 라운드, 상단 타이틀+칩, 회색 스케일 토큰 그대로 사용 |
| Portrait·Landscape 모두 설계 | `layout/`(2열) · `layout-port/`(1열 스크롤) 분리. 매니페스트에서 고정 방향 제거 |
| CarUxRestrictions 준수 | `UxRestrictions.kt`: NO_KEYBOARD 시 수신자 입력·텍스트 입력 차단 |
| 텍스트 입력보다 프리셋·음성 우선 | 목적지는 타일 선택, 질문은 음성(🎤). 키보드는 정차 중 설정에서만 |
| 상태 복원 | 엔진이 Application 에 상주, 화면 복귀 시 현재 상태 재렌더 |

## 2. 디자인 토큰 (`res/values/colors.xml`)
- Basic scale (Pleos Colors 문서): `#131417 #44464E #686A72 #A4A8AE #C7C9CE #E0E1E6 #EDEEF2 #F7F8FA #FFFFFF`
- Informative: active `#00E074`, positive `#0082FF`, negative `#FF4C28`
- Semantic: background=basic_800, surface=white, text=basic_100/300, button_primary=basic_100, accent=positive
- 다크: `values-night/colors.xml` (배경 #0E0F12, 카드 #1A1C21, 기본 버튼 흰색)
- 타입 스케일 (`dimens.xml`, 160dpi 기준 1dp=1px): display 120 / headline 56 / title 40 / body 30 / label 24 / caption 20 (최소 12sp 권장 충족)
- 컴포넌트: 필 버튼 96dp, 아이콘 버튼 88dp, 카드 패딩 32, 페이지 패딩 40, 토스트 가이드 패딩 24

## 3. 화면 (11/5 오후 내비 앱 문법으로 고도화)
> 티맵·네이버지도·카카오내비 사용자가 바로 읽을 수 있는 구조를 빌렸다: 목적지 목록 → 상세 시트 → [안내 시작], 주행 중에는 "다음 안내" 패널 + 경로 진행 바 + 하단 ETA 바 + **실제 지도**(도착 구역 확대). 순정 내비가 전체 경로를 맡고, 우리 지도는 마지막 300 m(정문·연석·주차장 입구·만남 지점)를 보여 준다.

### 지도 (`ZoneMap.kt`)
- 엔진: MapLibre Android 13.6.1 (오픈소스, 구글 플레이 서비스 불필요 — Pleos 에뮬레이터에 GMS 없음). 타일: OpenFreeMap `positron` 벡터 스타일(키·과금 없음, 라이트 톤이 Pleos 라이트 테마와 맞음). 라벨은 스타일 로드 후 `name:ko → name` 으로 한국어만 표시.
- 오버레이: OSRM 경로선(파랑, 흰 외곽) → 도착 반경(파랑 10%) → 정문 앞 연석 ±22 m(허용 초록 / 금지 빨강) → 차 마커(방위 회전) → 목적지 핀(줌 15.5 미만) / 지점 심볼(줌 15.5 이상: 정문·주차장 입구·만남·진입 금지, 라벨+메모 2줄).
- 지점 좌표 = 정문(목적지 좌표) + `zone[].offsetM` × 도로 방위 `roadBearing`, 보도 쪽 −16 m / 도로 쪽 +12 m (`ZoneGeo`).
- 카메라: 차 + 도착 구역 전체가 보이게 fit(최대 줌 19). 사용자가 손으로 움직이면 8초간 유지 후 복귀. 자동 애니메이션 없음(`moveCamera`).
- 하나의 MapView를 출발 전 상세 카드 / 안내 중 카드 / 도착 카드 슬롯으로 옮겨 쓴다(TextureView 모드, 라운드 클립). 스타일 로드 실패(오프라인) 시 MapView 를 숨기고 아래 깔린 `ZoneSketchView` 가 보인다.
- 저작권 표기: 카드 아래 "© OpenFreeMap · OpenMapTiles · OpenStreetMap" + MapLibre 기본 어트리뷰션 버튼.

### 커스텀 뷰
- `RouteProgressView`: 남은 거리를 구간별(>3km 12% / 3~1km 33% / 1km~300m 30% / 300m~0 25%)로 매핑해 라스트마일을 넓게 보여 주는 진행 바. 지나간 이정표는 채움, 차 마커는 검정 원 + 방향 화살표.
- `ZoneSketchView`: `destinations.json`의 `zone[]`(type entrance/parking/meeting/noentry, 정문 기준 m 오프셋, note)로 건물–보도–도로 도식을 그린다. 축척 대신 순서 기반 균등 배치(라벨 겹침 방지), 정문 앞 연석을 정차 허용(초록)/금지(빨강) 띠로, 정문↔주차장 입구 거리를 화살표로 표기. 도착 후에는 차 마커를 정문 위치로.
- 모두 자동 애니메이션 없음(주행 규제), 색은 `R.color.*` 토큰이라 다크 모드 자동 대응.

### 상태 처리 보강
- 완료 후 내비가 같은 목적지를 다시 알려도 재시작하지 않도록 완료한 목적지 id를 SharedPreferences에 저장(앱 재시작 포함). 완료 시 내비 경로는 취소하지 않는다(취소하면 내비가 앞 창으로 튀어나옴).

## 5. 알려진 제약
- `안내 종료` 시 내비 경로 취소 → 내비가 앞으로 옴. 앱으로 돌아오려면 GNB 앱 라이브러리에서 선택 (Pleos 윈도 정책).
- 에뮬레이터 온디바이스 TTS 오류 → Android TTS 폴백. 실차는 Pleos TTS.
- 지도 타일(OpenFreeMap)·경로선(OSRM 데모 서버)은 공개 무료 서비스라 상용 배포 시 자체 타일/경로 서버 또는 유료 플랜으로 교체 필요. 다크 모드용 지도 스타일은 미적용(positron 고정).
- Virtual Console HTTP API(`PUT /vehicle/gear`)는 콘솔 페이지가 브라우저에 열려 있을 때만 200.
