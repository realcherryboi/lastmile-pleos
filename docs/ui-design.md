> 2026-11-05. 근거: document.pleos.ai 디자인 가이드(Introduction·Display Layout·Window Policy·Typography·Colors·Interaction), 앱 리뷰 가이드(운전자 주의 분산·기능/성능 안정성), 앱 구조 모델, 주행 규제 개발 가이드. 순정 내비·클러스터 화면을 시각 레퍼런스로 사용.

## 3. 화면 (11/5 오후 내비 앱 문법으로 고도화)
> 티맵·네이버지도·카카오내비 사용자가 바로 읽을 수 있는 구조를 빌렸다: 목적지 목록 → 상세 시트 → [안내 시작], 주행 중에는 "다음 안내" 패널 + 경로 진행 바 + 하단 ETA 바 + **실제 지도**(도착 구역 확대). 순정 내비가 전체 경로를 맡고, 우리 지도는 마지막 300 m(정문·연석·주차장 입구·만남 지점)를 보여 준다.

### 지도 (`ZoneMap.kt`)
- 엔진: MapLibre Android 13.6.1 (오픈소스, 구글 플레이 서비스 불필요 — Pleos 에뮬레이터에 GMS 없음). 타일: OpenFreeMap `positron` 벡터 스타일(키·과금 없음, 라이트 톤이 Pleos 라이트 테마와 맞음). 라벨은 스타일 로드 후 `name:ko → name` 으로 한국어만 표시.
- 오버레이: OSRM 경로선(파랑, 흰 외곽) → 도착 반경(파랑 10%) → 정문 앞 연석 ±22 m(허용 초록 / 금지 빨강) → 차 마커(방위 회전) → 목적지 핀(줌 15.5 미만) / 지점 심볼(줌 15.5 이상: 정문·주차장 입구·만남·진입 금지, 라벨+메모 2줄).
- 지점 좌표 = 정문(목적지 좌표) + `zone[].offsetM` × 도로 방위 `roadBearing`, 보도 쪽 −16 m / 도로 쪽 +12 m (`ZoneGeo`).
- 카메라: 차 + 도착 구역 전체가 보이게 fit(최대 줌 19). 사용자가 손으로 움직이면 8초간 유지 후 복귀. 자동 애니메이션 없음(`moveCamera`).
- 하나의 MapView를 출발 전 상세 카드 / 안내 중 카드 / 도착 카드 슬롯으로 옮겨 쓴다(TextureView 모드, 라운드 클립). 스타일 로드 실패(오프라인) 시 MapView 를 숨기고 아래 깔린 `ZoneSketchView` 가 보인다.
- 저작권 표기: 카드 아래 "© OpenFreeMap · OpenMapTiles · OpenStreetMap" + MapLibre 기본 어트리뷰션 버튼.

### 커스텀 뷰
- `RouteProgressView`: 남은 거리를 구간별(>3km 12% / 3~1km 33% / 1km~300m 30% / 300m~0 25%)로 매핑해 라스트마일을 넓게 보여 주는 진행 바. 지나간 이정표는 채움, 차 마커는 검정 원 + 방향 화살표.
- `ZoneSketchView`: `destinations.json`의 `zone[]`(type entrance/parking/meeting/noentry, 정문 기준 m 오프셋, note)로 건물–보도–도로 도식을 그린다. 축척 대신 순서 기반 균등 배치(라벨 겹침 방지), 정문 앞 연석을 정차 허용(초록)/금지(빨강) 띠로, 정문↔주차장 입구 거리를 화살표로 표기. 도착 후에는 차 마커를 정문 위치로.
- 반복 애니메이션 없음(주행 규제). 값 변화는 임계감쇠 스프링으로 이어진다. 색은 `R.color.*` 토큰이라 다크 모드 자동 대응.

### 모션 (`Motion.kt`) — Apple Fluid Interfaces 원칙을 Pleos 톤 안에서
- 고정 시간(duration) 애니메이션 대신 **스프링**(`androidx.dynamicanimation`). Apple 식 두 파라미터로 생각한다: response(초)·damping ratio. 환산 `k = (2π/response)²`.
  - 기본 `Default` 0.38 / 1.0(임계감쇠, 오버슈트 없음) · 누름 `Press` 0.14 / 1.0 · 해제 `Release` 0.32 / 0.62 · 시트 `Sheet` 0.34 / 0.82(Apple 드로어 값) · 값 `Value` 0.55 / 1.0 · 순간 강조 `Pop` 0.42 / 0.55
  - 바운스는 제스처 에너지가 실린 경우(누름 해제·시트 던지기)와 도착·이정표 통과 같은 "순간"에만. 그냥 나타나는 요소는 전부 임계감쇠.
- **중단 가능**: 모든 스프링은 현재 값·속도에서 이어진다(`animateToFinalPosition`). 전환 중 상태가 다시 바뀌어도 점프 없음.
- **공간 일관성**: 페이지 전환은 앞으로(출발→안내→도착) 새 화면이 아래에서 올라오고 이전 화면은 뒤로 물러남, 뒤로(→출발 전)는 그 역경로. 배너·카드·상세 시트도 들어온 길로 나간다.
- **값 스프링** `SpringValue`: 남은 거리·다음 안내까지 거리는 숫자가 카운팅되며 바뀌고, 진행 바 차 마커와 정차 타이머 바는 연속으로 움직인다. 이정표를 지나면 그 노드가 1.6→1.0 으로 튀며 채워진다.
- **시트 = 재질**: 음성 시트는 아래에서 Sheet 스프링으로 올라오고, 뒤 화면은 블러(RenderEffect, API 31+) + 96.5% 축소로 밀려난다(Apple "모달은 배경을 뒤로 민다"). 설정·개발자 시트도 같은 밀어내기. 시트는 손가락과 1:1로 끌리고(위로는 러버밴드), 놓으면 속도를 이어받아 투영 지점(`project(v) = v/1000·d/(1−d)`, d=0.998)으로 닫힘/복귀를 결정한다.
- **시스템 "애니메이션 끄기"**(animator duration scale 0) 면 즉시 최종값 — 모션 감소 대응.

### 유리 재질 (Liquid Glass 풍, 지도 위에만)
- `bg_glass`/`bg_glass_circle`/`bg_sheet_glass`: 반투명 흰 유리(위 96%→아래 84%) + 밝은 1.5dp 테두리(빛 받는 모서리) + elevation 그림자. 지도처럼 배경이 움직이는 곳에서만 쓴다 — 흰 카드 위에 유리를 겹치지 않는다(가독성).
- 지도 슬롯 공통 오버레이 `view_map_glass.xml`: 좌상 제목 캡슐(출발 전 "도착 구역 미리보기" / 안내 중 "도착 구역 · 목적지" / 도착 "만남 · 지점"), 우하 **현재 위치로** 버튼(카메라 복귀), 좌하 출처 캡슐. 카드 안의 제목 행·캡션은 지도 안으로 들어가 지도가 더 커졌다(안내 500dp, 도착 440dp).
- 음성 시트 배경을 유리로 바꾸고 상단에 그랩 핸들. 뒤가 블러라 실제 유리처럼 읽힌다.

### 임의 목적지 (A) · 차량 신호 심화 (C) — 11/5 저녁
- **임의 목적지**: NaviHelper `onDestinationInfo(name, lat, lng)` 가 등록 장소와 안 맞으면 `Destination.generic()` 으로 바로 ARMED. `rulesKnown=false` 라 안내 문장이 "정차 규칙 정보가 없는 곳이라 일반 도로 기준 5분 이내 정차로 안내할게요"로 바뀌고, 상세 사실 행에 "일반 도로 기준"을 표시한다.
- **보강(OsmEnricher)**: 주소는 Nominatim 역지오코딩(키 없음, User-Agent 필수), 주차장·충전소·도로 방위는 `ZoneMap.nearby()` 가 이미 내려받은 OpenFreeMap 벡터 타일의 `poi`(class parking / charging_station)·`transportation` 레이어를 `VectorSource.querySourceFeatures` 로 조회한다. 서버 호출이 없어 Overpass 같은 공개 API의 과부하(테스트 중 502)에 흔들리지 않는다. 지도가 멈출 때(onDidBecomeIdle) 최대 6회 재시도. 찾은 주차장은 절대 좌표 `ZoneSpot(lat,lng)` 로 지도에 찍힌다. 에뮬레이터 검증: 판교역 → "판교공영주차장 166 m", 주소 "경기도 성남시 분당구 판교역로146번길".
- **차량 신호**: 우측 방향지시등(300 m 이내) → STOPPING, 승객석 문(조수석·뒷좌석) 열림→닫힘(ARRIVED 이후) → DONE "승하차 확인했어요"(정차 타이머 '완료', 버튼 '출발'), EV SoC ≤20% → 3 km 브리핑에 충전기 문장 + 안내 중 카드에 배터리 행. 모두 `TripStateMachine` 이벤트(TurnSignal/Door/EvSoc)로 들어온다. Virtual Console 주입: `PUT /vehicle/turn-signal?mode=BlinkRight`, `PUT /vehicle/body?door_fr=true|false`, `PUT /vehicle/ev-battery?field=soc&value=18` (브라우저 세션 하트비트 필요).

### 지도 모션 (키 없음)
- 3D 건물: 타일 `building` 레이어를 `FillExtrusionLayer`(render_height) 로, 줌 15 이상. 목적지 좌표 위 건물은 `queryRenderedFeatures` 로 찾아 파랑 3D 로 강조(`lm-3d-dest`).
- 카메라: `getCameraForLatLngBounds(bounds, padding, bearing, tilt)` → `easeCamera` 900 ms. 주행 중 헤딩업(차 방향이 위) + 기울기 45°, 도착 38°, 미리보기 32°. 사용자가 손으로 움직이면 8초 유지.
- 차 마커: 위치(기준점 기준 m 오프셋)·방향(최단 회전)을 `SpringValue` 로 보간 → GPS 갱신마다 점프하지 않는다.
- 경로선: `lineMetrics` 소스 + `line-gradient`. 경로 로드 시 0→1 로 그려지고(reveal 스프링), 차 위치에 가장 가까운 경로점까지는 회색, 남은 구간은 파랑.
- 도착 펄스: ARRIVED 진입 시 도착 반경 채움을 0.38→0.10 으로 한 번 가라앉힌다(반복 없음).

### 목적 선택 · 차선 규칙 — 11/6 00시
- 목적지마다 **정차 · 픽업 / 도착 후 주차 / 경유** 칩(`view_purpose.xml`, 상세 카드와 안내 중 카드 양쪽). 정차 금지 장소는 주차가 기본(`TripPurpose.defaultFor`). 출발 전에 고른 값은 내비가 목적지를 돌려줄 때 적용되고, 안내 중 바꾸면 다음 브리핑부터 반영.

- **안내 중 · 반 창**(`layout-port/block_drive_hero.xml`·`block_drive_info.xml`·`page_drive.xml`): 한 열 스크롤. 지도는 내비가 바로 왼쪽에 있으니 접는다(슬롯 0dp). 다음 안내 카드는 세로형(라벨+카운트다운 한 줄, 제목 40, 미리보기), 충전 버튼은 전체 폭.
- **도착 · 전체 창**(`layout/page_arrived.xml`): 왼쪽 60% = 배지+제목(64)·주소 → 카드 2장 나란히(정차 타이머/주차장 · 승하차 대기) → 완료. 오른쪽 40% = 도착 구역 지도. **반 창**(`layout-port/page_arrived.xml`): 제목 52 → 카드 2장 세로 → 지도(남는 높이) → 완료.
- 승하차 카드는 상태에 따라 바뀐다: "승하차 기다리는 중 / 승객석 문이 열렸다 닫히면 끝나요…" → 문이 닫히면 "승하차 끝 / 내린 자리: 정문 지나서 20 m. 다음에 오면 이 자리를 먼저 알려 드려요." 제목 줄은 "승하차 확인했어요 · 문이 닫혔어요 · 안전 운전하세요"로만 두어 반 창에서 잘리지 않는다.
- 주차 목적일 때 사실 카드의 정문 줄은 "황색 실선 · 주차 목적이라 건너뜀"처럼 규칙은 보이되 판정은 건너뛴다는 뜻을 같이 적는다.
- 확인: 에뮬레이터 전체·반 창에서 안내 중(1 km·300 m)·도착·승하차 완료 화면 캡처로 시안과 대조. 영상은 아직 찍지 않는다(대표 지시).
