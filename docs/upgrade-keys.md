# 고도화 항목 — 외부 키·계정이 필요해 미뤄 둔 것 (2026-11-10 정리)

1차 제출본은 **Pleos SDK + 키 없는 공개 서비스**만으로 전 기능이 돈다(1인 참가라 키 발급·운영 부담과 심사 중 외부 서비스 끊김 위험을 피하려는 선택). 아래는 같은 자리를 더 좋은 유료·키 기반 서비스로 바꿀 때의 목록이다. 코드에는 이미 바꿔 끼울 자리가 있다(`app/keys.properties` → `BuildConfig`, 비어 있으면 해당 기능은 조용히 꺼진다).

## 순서 제안 (키를 받는 대로)
1. **공공데이터포털 키 1개**(충전소·주차장 둘 다 같은 계정): 코드 자리가 이미 있어 가장 빨리 효과가 난다. 2차 PT 전 목표.
2. **MapTiler 키**: 스타일 URL 한 줄 교체로 지도 품질·다크 모드가 올라간다.
3. **카카오 개발자 키**: 역지오코딩·길찾기를 국내 데이터로.
4. **TTS(ElevenLabs 또는 클로바 보이스)**: 2차 PT 영상·발표 나레이션부터 적용. 앱 내 전용 목소리는 그다음.
5. 정밀도로지도·백엔드·알림톡은 수상 이후 과제.

## 기획서(docs/proposal.md)에 넣을 자리와 문단 초안 — [대표 확인]

기획서는 대표가 직접 손보므로 여기 초안만 둔다. 표 형식은 기획서 톤에 맞춰 줄였다.

**① 5장 5-1 표 "데이터" 행, 2차 PT 열** (현재: "실제 장소 5~10곳으로 교체(현장 확인한 차선), 공공데이터 연동(주차장·충전소)")
> 실제 장소 5~10곳으로 교체(현장 확인한 차선), 공공데이터 연동(충전소 실시간 상태·주차장 요금 — 키 자리는 1차 코드에 이미 있음)

**② 5장 5-3 "1인 개발 리스크" 표 뒤, 또는 5-2 표 바로 아래에 새 단락**
> **외부 서비스는 키 없는 공개 서비스로 먼저 완성했다.** 지도는 MapLibre + OpenFreeMap, 주소는 OpenStreetMap, 경로선은 OSRM, 음성은 Pleos TTS 로 전 기능이 키 없이 돈다. 같은 자리에 더 좋은 서비스를 끼울 수 있게 설정 자리(`keys.properties`)를 두었고, 2차까지 공공데이터포털(충전소 실시간 상태·주차장 요금)을 먼저 연결한다. 지도 타일(MapTiler)·국내 지오코딩(카카오 로컬)·전용 안내 음성(ElevenLabs 또는 네이버 클로바 보이스)은 키를 받는 대로 교체하되, 차량 안 기본 안내 음성은 플랫폼 표준인 Pleos TTS 를 유지한다.

**③ 6장 "향후 서비스 확대 계획" 1번 데이터 항목 끝에 한 문장 추가**
> 지도·주소·음성 같은 바탕 서비스는 키 기반 상용 서비스(MapTiler, 카카오 로컬, ElevenLabs·클로바 보이스)로 올려 품질을 맞춘다.

**④ 7장 참고자료**에는 넣지 않는다(출처가 아니라 계획이므로).
